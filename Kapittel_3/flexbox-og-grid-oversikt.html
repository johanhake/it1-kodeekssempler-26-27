Flexbox og Grid – CSS-egenskapene vi har gått gjennom

Hvert lille eksempel under er ekte CSS: boksen bruker akkurat den verdien som står over den. Kortet med farget kant er standardverdien – det du får hvis du ikke skriver noe.

Container = forelderen. Den får display: flex eller display: grid, og bestemmer hvordan barna plasseres. 
.container {
  display: flex; /* eller grid */
}
Item = hvert barn rett inni containeren. Item-egenskaper skrives på barnet og gjelder bare det ene elementet. 
.container > .item {
  flex-grow: 1;
}
Fargekode i eksemplene
Nummererte bokser er items. Den brune er itemet egenskapen er satt på. Den lyse flaten er containeren.

Flexbox

Flexbox legger items på én linje – enten vannrett eller loddrett.

flex-direction bestemmer retningen på hovedaksen. justify-content fordeler items langs hovedaksen.

align-items og align-self plasserer items langs tverraksen.

Med flex-direction: column bytter aksene plass: da blir justify loddrett og align vannrett.

Grid

Grid deler containeren i kolonner og rader – i to retninger samtidig.

grid-template-columns og grid-template-rows lager sporene (tracks). Enheten fr betyr «en andel av plassen som er igjen».

Mellom sporene går gridlinjer. Items plasseres med linjenummer: grid-column: 2 / 4 = fra linje 2 til linje 4. -1 er alltid siste linje.

justify-… virker vannrett (langs radene), align-… loddrett (langs kolonnene).

Container Egenskaper på grid-containeren

Huskeregel: justify-items / align-items flytter hvert item inni sin egen celle. justify-content / align-content flytter hele rutenettet inni containeren – det virker bare når sporene til sammen er mindre enn containeren.
